Forensic Gait Biometric Verification Engine

"Explainable Kinematic Analysis & Temporal Alignment for Video Forensics — Overcoming Black-Box AI Inadmissibility in Masked-Suspect CCTV Evidence."

Problem Statement

In modern criminal investigations (armed robbery, burglary, transit violence), surveillance CCTV footage regularly fails to capture usable facial biometrics.

  • Masked Suspect Vulnerability: Facial recognition is rendered 100% ineffective when perpetrators intentionally obscure their face using balaclavas, surgical masks, or hoodies.
  • Courtroom Inadmissibility of Black-Box AI: End-to-end Deep Learning models fail judicial evidentiary standards (Daubert & Frye standards) because opaque latent vectors lack scientific explainability.
  • Critical Deterministic Need: Necessity for an explainable, scale-invariant, and scientifically verifiable biometric tool grounded in Newtonian joint kinematics.

CCTV Facial Recognition Failure

Low capture angles, resolution degradation, and physical facial coverings leave body gait and stride kinematics as the only unmasked biometric signature.

The Legal Daubert Standard Barrier

Courts mandate transparent, peer-reviewable methodologies with demonstrable error bounds. Black-box embeddings cannot be audited under cross-examination.

Literature / Existing Work

Black-Box CNNs & Deep Gait Recognition

Conventional state-of-the-art models (GaitSet, GaitPart, 3D-CNNs) extract high-dimensional latent space embeddings from silhouette sequences:

  • Highly vulnerable to adversarial noise, loose clothing, and carrying variations.
  • Zero biological or Newtonian explainability for expert courtroom testimony.
  • Lacks chain-of-custody cryptographic integrity guarantees.

Proposed Solution

Deterministic Model-Based Kinematic Pipeline

A three-stage transparent architecture enforcing cryptographic proof, geometric angle extraction, and elastic temporal alignment:

  • SHA-256 Chain-of-Custody: Immutable evidentiary digital hashing.
  • Vector Trigonometry: Scale-invariant knee flexion tracking (120°–175°).
  • Dynamic Time Warping (DTW): Non-linear temporal pace alignment.

System Architecture & Workflow

Polyglot automated execution coordinated by POSIX Shell pipeline

Stage 1

Ingestion & Integrity Seal

POSIX Shell (src/ingest.sh) computes SHA-256 cryptographic hashes for suspect and reference videos, logging ISO 8601 UTC timestamps into an immutable audit manifest (output/evidence_manifest.jsonl).

POSIX sh • sha256sum
Stage 2

Skeletal Kinematic Extraction

Python (src/extract_gait.py) runs MediaPipe Pose keypoint tracking on Hip (23/24), Knee (25/26), and Ankle (27/28), applying atan2 vector trigonometry to extract knee flexion angles (120°–175°).

Python 3 • MediaPipe • OpenCV
Stage 3

Temporal Alignment Engine

Compiled Java backend (src/GaitVerifier.java) executes an O(N×M) Dynamic Programming DTW recurrence matrix, elastically aligning time-shifted walking strides to output cumulative warping cost.

Java 17 Bytecode • DP Engine

Multi-Threaded Batch Comparison

Upgrading Java DTW engine with java.util.concurrent.ExecutorService thread pools to cross-verify suspect kinematics against multi-camera CCTV repositories in parallel.

Low-Pass Butterworth Filter

Introducing zero-phase digital Butterworth filtering in Python signal processing to eliminate landmark tracking jitter and high-frequency noise from low-frame-rate surveillance feeds.

Bayesian Likelihood Ratio (LR) Calibration

Calibrating DTW scores against intra-person and inter-person variance distributions from the CASIA-B dataset to provide court-admissible Bayesian Likelihood Ratios (LR = P(E|Hp) / P(E|Hd)).

Automated Courtroom PDF Dossier

Programmatic export of tamper-proof forensic audit reports containing SHA-256 evidence digests, time-series kinematic wave plots, and warping matrices formatted for legal testimony.
